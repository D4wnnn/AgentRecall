# Recall versus legitimate update

This prompt set contains one ordinary recall case and two explicit state-update cases. Run
local-only, fixed-10, and all-layer variants with identical seed. Inspect whether stronger
memory improves the recall case but restores an obsolete coat or object location in update
cases. Such an opposing effect is direct motivation for a memory-validity gate.

The three prompts are synthetic diagnostics created for this project, not paper data.
