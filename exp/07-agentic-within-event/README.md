# 07: Within-event key-chunk selection

Experiment 06 established that a controlled semantic plan can force the intended event
chunks into LayerRecall without increasing the two-chunk visible-memory budget. It also
showed that choosing the two final chunks of the first event can preserve temporal stability
while still allowing suitcase color drift late in the return shot.

This follow-up keeps the whole 160-frame sequence physically resident and compares three
equal-budget plans during return chunks 12--19:

- `agent_early`: chunks 2 and 1;
- `agent_late`: chunks 7 and 6;
- `agent_mixed`: chunks 7 and 2.

The test asks whether an agent must choose not only the correct event, but complementary
key chunks within that event. A positive mixed-plan result motivates multi-slot/event-aware
memory; no meaningful difference suggests that a more elaborate agent is unnecessary.
